# 手机端重设计：对话优先的四页结构

**日期：** 2026-11-06
**状态：** 已确认，可实施
**范围：** `mobile/` Flutter 客户端

## 为什么改

现在手机端是 Web 的缩小版：底部是工作台 / 文件 / 笔记 / 音乐 / AI，日程、待办、通知、搜索藏在工作台里，刚完成的幕僚长和记忆审核没有入口。用户最主要的动作是 **AI 聊天**，但聊天被放在最后一个 tab，首屏是统计卡和最近文件。

这次重设计做两件事：

1. **重新规划功能**：4 个 tab，聊天成为第一入口，工作台成为默认首页，所有插件/业务对象集中到「空间」。
2. **整体美化**：晴空蓝视觉、暖色高光、统一圆角和层级；主题色可配置并跨端同步。

## 目标

- 底部只有 4 个 tab：**对话 / 工作台 / 空间 / 我的**。
- 进入 App 默认落在 **工作台**。
- 工作台第一屏回答三个问题：现在最该做什么、有什么在等我、AI 能替我做什么。
- 所有插件与业务对象（邮件、钉钉、通知、日程、待办、项目、幕僚长、文件、笔记、资讯、设备、音乐、实验室）都能在「空间」找到。
- 主题色支持预设 + 自定义，背景 tint 可开关，深浅模式独立，字号可调。
- 保留现有能力：聊天流式输出、历史会话、文件、笔记、日程、待办、通知、音乐、设备、VibeCoding、记忆审核。

## 非目标

- 不改后端业务逻辑；只消费已有 API。
- 不改 Web/桌面布局。
- 不新增个人微信能力。
- 不在本次实现会议准备的完整表单；先提供简报与周报入口。
- 不做复杂的离线缓存或本地数据库。

## 视觉系统

### 颜色（晴空蓝）

| Token | 值 | 用途 |
|---|---|---|
| primary | `#2E7CF6` | 发送、用户气泡、链接、选中态 |
| primaryLight | `#6AA8FF` | 渐变起点 |
| primarySoft | `#E8F1FF` | 浅色底、标签、图标底 |
| background | `#F2F7FF` | 页面背景（tint 开启时由主题色派生） |
| card | `#FFFFFF` | 卡片 |
| ink | `#16233B` | 主文字 |
| muted | `#7C8AA5` | 次文字 |
| line | `#E3ECF9` | 分割线/边框 |
| accent | `#FF7A59` | 紧急、提醒、强调 |

其他预设：薄荷绿 `#0FA97A`、暖阳橙 `#F97316`、樱花粉 `#E0507F`。

### 形状与间距

- 卡片圆角 16，输入框 12–16，底部 dock 20，手机整体 38。
- 页面左右边距 16；卡片内边距 12–14；卡片间距 8–10。
- 字号：页面标题 18–20，卡片标题 13–14，正文 12–13，辅助 10–11。
- 阴影只用于 AI 卡片和底部 dock，其他卡片用 1px 边框。

### 主题派生

- `primary` 由用户选择；`primarySoft` = primary 与白色按 12% 混合；`primaryLight` = primary 与白色按 32% 混合。
- `background` = tint 开启时 primary 与白色按 7% 混合，否则 `#F6F8FC`。
- 深色模式使用 `ColorScheme.fromSeed(seedColor: primary, brightness: dark)`，背景 `#111318`，卡片 `#1A1D24`。
- tint 关闭时，背景保持中性浅色，不随主题色变化。

## 信息架构

```
HomeScreen
├─ 0 对话        ChatListScreen → ChatScreen
├─ 1 工作台      WorkbenchScreen（默认）
├─ 2 空间        SpaceScreen
└─ 3 我的        ProfileScreen
```

### 对话

- 进入「对话」tab 直接打开最近一条会话；没有会话时显示新对话。
- 点击顶部标题打开会话切换面板，可在最近会话之间切换，或点「新对话」开始新的会话。
- 会话详情：标题/切换、引用条、消息流、流式输出、来源引用、生成待办、输入区（附件/引用/发送）。
- 不再提供「普通 / Agent」模式选择：对话默认按需调用工具，避免让用户做无意义的选择。

### 工作台（默认）

- 顶部：问候、日期、搜索、头像。
- AI 卡片：深色/主题色渐变，输入框，3 个快捷提示。
- 今日：2 条日程 + 到期/逾期待办提示。
- 信息：待处理数、邮件/钉钉拆分、紧急预览。
- 幕僚长：今日简报摘要 + 查看。
- 文件与笔记：最近文件 + 进入合并页。

### 空间

- 顶部：空间、副标题「所有应用与业务对象」、搜索、管理。
- 置顶：统一收件箱（待处理数、紧急数）。
- 分组：沟通（邮件/钉钉/通知）、工作（日程/待办/项目/幕僚长）、内容（文件/笔记/资讯）、更多（音乐/设备/实验室）。
- 每个 tile 有图标、名称、角标；新增插件自动归入分组。
- 点击进入对应功能页。

### 我的

- 资料卡、编辑。
- 智能：记忆与关于我、幕僚长偏好。
- 外观：外观与主题、通知与提醒。
- 连接：设备、MCP 与集成、音乐、实验室。
- 退出登录。

### 外观与主题

- 主题色：4 个预设 + 自定义色相；实时预览。
- 模式：跟随系统 / 浅色 / 深色。
- 背景跟随主题色开关。
- 字体大小：小 / 标准 / 大。
- 修改即保存；登录后 best-effort 同步到 `/api/sync/settings/appearance/{key}`。

## 数据来源

| 页面 | API |
|---|---|
| 会话列表 | `GET /api/chat/sessions` |
| 会话历史 | `GET /api/chat/history?session_id=` |
| 聊天 | `POST /api/chat/stream`、`POST /api/chat/agent` |
| 工作台简报 | `GET /api/cos/daily-brief` |
| 统一收件箱 | `GET /api/cos/triage` |
| 周报 | `GET /api/cos/weekly-review` |
| 回复草稿 | `POST /api/cos/draft-reply` |
| 邮件 | `GET /api/plugins/mail/messages` |
| 日程 | `GET /api/schedule` |
| 待办 | `GET /api/plugins/todo/items` |
| 通知 | `GET /api/notifications` |
| 文件 | `GET /api/files` |
| 笔记 | `GET /api/plugins/notes/tree` |
| 资讯 | `GET /api/rss/entries` |
| 项目 | `GET /api/projects` |
| 记忆 | `GET /api/memory/candidates`、`GET /api/memory/records` |
| MCP | `GET /api/mcp/servers` |
| 主题同步 | `GET/PUT /api/sync/settings/appearance/{key}` |

所有请求失败时显示空状态或上次数据，不阻塞页面；没有 LLM key 时简报/周报走后端确定性降级。

## 关键行为

- 默认 tab = 工作台（index 1）。
- 切换 tab 保留各页状态（`IndexedStack`）。
- 聊天流式失败时显示错误气泡，可重试。
- 主题切换立即生效，不需要重启。
- 退出登录清除 token 和本地主题之外的用户数据缓存。
- 空间 tile 在 API 不可用时仍显示，角标隐藏，点击进入空状态页。

## 可访问性

- 正文对比度 ≥ 4.5:1；主色按钮文字为白色。
- 所有可点击区域 ≥ 44×44。
- 字体缩放通过 `MediaQuery.textScaler`，最大 1.3，避免布局溢出。
- 深色模式不使用纯黑，降低眩光。

## 验收

- `flutter analyze` 无 error。
- `flutter test` 通过。
- 4 个 tab 顺序正确，默认工作台。
- 主题色、tint、模式、字号修改后立即生效并被持久化。
- 主要页面在 360×800 和 390×844 下无溢出。
- 聊天、工作台、空间、我的均能在无网络时显示可理解的空状态。
